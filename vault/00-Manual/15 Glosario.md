# 15 · Glosario

| Término | Qué es |
|---|---|
| POST | Autoprueba de encendido. El chequeo del firmware antes de cargar el sistema operativo |
| BIOS / UEFI | El programa base de la tarjeta madre que arranca el equipo. UEFI es la versión moderna |
| S.M.A.R.T. | Sistema de autovigilancia del disco que reporta si se está deteriorando |
| SFC | *System File Checker.* Verifica y repara archivos del sistema de Windows |
| DISM | Repara la imagen base de Windows que usa SFC |
| CMOS | Memoria del BIOS alimentada por la pila de moneda; guarda fecha, hora y configuración |
| ESD | Descarga electrostática. La chispa invisible que daña componentes |
| DHCP | Servicio que reparte direcciones IP automáticamente en la red |
| DNS | Servicio que traduce nombres como google.com a direcciones IP |
| RLS | *Row Level Security.* La regla de Postgres que hace que cada estudiante vea solo sus hojas |
