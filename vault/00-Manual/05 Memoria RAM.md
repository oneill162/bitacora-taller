# 05 · Memoria RAM

La RAM mala produce pantallas azules aleatorias, congeladas y programas que cierran solos.

```
mdsched.exe
```

Escoge *Reiniciar ahora y comprobar si hay problemas*. El equipo reinicia y corre la prueba antes de Windows. Al volver, el resultado queda en el Visor de eventos bajo el origen `MemoryDiagnostics-Results` — ver [[13 Visor de eventos]].

> [!tip] Si da error
> Apaga, saca todos los módulos menos uno y repite la prueba con cada módulo por separado y en distintas ranuras. Así separas si el malo es el módulo o la ranura de la tarjeta madre.
